# Web Technologies Mini Project — StudyTrack

This repository contains **StudyTrack**, a Student Assignment & Deadline Manager built with Python, Django MVT, MySQL, Bootstrap 5, and JavaScript.

## Quick Start
The complete project codebase, documentation, migrations, seed script, and automated tests are located in the [`studytrack/`](file:///c:/Users/Yashodhara%20Heggade/Documents/antigravity/Web-tech/studytrack/) directory.

```bash
cd studytrack
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python manage.py migrate
python seed_demo_data.py
python manage.py test
python manage.py runserver
```

For full documentation, database ER diagrams, syllabus mapping, and viva questions, please refer to [`studytrack/README.md`](file:///c:/Users/Yashodhara%20Heggade/Documents/antigravity/Web-tech/studytrack/README.md).
